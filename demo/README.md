# PITFALL — демо

Проверка корректности признаков по времени **дифференциальным исполнением**.

```
φ(D, t) = φ(D|t, t),   D|t = { r ∈ D : avail(r) ≤ t }
```

Программа признаков вызывается дважды: на полной базе и на базе, физически усечённой
на момент предсказания. Расхождение выходов — **доказательство** нарушения, а не подозрение.
Ни код, ни SQL не разбираются: программа — чёрный ящик. Ложных срабатываний нет по построению.

## Запуск

```bash
python3 demo.py            # три сцены, всё считается вживую, ~1 минута на 2 ядрах CPU
python3 demo.py 2          # одна сцена
python3 demo.py --no-color # без ANSI, для записи в лог
python3 make_page.py       # собрать pitfall_demo.html из demo_results.json
```

Зависимости — `../requirements.txt` (см. корневой README, окружение `../.venv`). Данные — Olist
в `../PITFALL_olist_data/` (7 таблиц, 112 650 позиций заказов, 2016-09 — 2018-10), другой
каталог — через переменную `PITFALL_DATA`.

## Три сцены

| | что | оракул | промышленная проверка | завышение |
|---|---|---|---|---|
| 1 | featuretools с настройками по умолчанию (`ft.dfs` без таблицы моментов) | **УТЕЧКА**, 11 колонок | **пропуск** (0.809 < 0.85) | **+14.8…+16.3 п.п.** |
| 2 | наш собственный эталон, первая версия | **УТЕЧКА**, 4 колонки | **пропуск** (0.687 < 0.85) | **+3.1…+5.3 п.п.** |
| 3 | тот же эталон после исправления | ЧИСТО | верно молчит | 0.00 |

Сцена 1 — поведение популярной библиотеки по умолчанию, а не наша симуляция.
Сцена 2 — ошибка, найденная оракулом в коде авторов самого оракула.
Сцена 3 — отрицательный контроль: без него первые две ничего не стоят.

## Границы метода

- **Изменяемое поле без истории непроверяемо.** У `order_status` нет метки времени; усечённая
  база для такой колонки неотличима от полной. Признак `canceled` исключён из всех режимов.
- **Недетерминированная программа** даёт расхождение без утечки — нужен фиксированный seed.
- **Пропуски возможны:** утечка, не проявившаяся на конкретном моменте `t`, на нём не видна.
  Ложных срабатываний при этом нет — асимметрия сознательная.
- Одна база, три задачи, три момента предсказания. Предварительный результат.

## Ошибка, найденная отрицательным контролем

В первой версии оракула `frames_equal(None, None)` возвращал `False`: программа, забывшая
`return`, детерминированно давала `None` на обоих вызовах и получала вердикт УТЕЧКА.
Баг найден отрицательным контролем **до** основного эксперимента; переаудит 23 вердиктов
показал 1 ложный. В `pitfall.py` этот случай обрабатывается явно.
