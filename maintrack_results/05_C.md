# C — расширения

## C1 — исправления

**Статус реестра:** done. Из-за отсутствия `pit-repair` применён самописный семантический механизм к 60 мутационным случаям; для каждого из четырёх слоёв CLEAN@1/2/3 составил 33,3%/66,7%/100%.

**Вердикт:** результат подтверждён для выбранных контролируемых семантических починок; он не доказывает способность автоматически исправлять произвольный исходный код. Последующая проверка отдельных буквальных правил на новых вариантах также выявила ограничения.

**Источники:** [отчёт C1](../docs/experiments/c1-maintrack-repair.md), [последующая проверка X9](../docs/experiments/followup-2026-10-21.md).

## C2 — дополнительные базы

**Статус реестра:** done. В расширительном историческом replay взята одна бинарная задача из каждой базы Stack, Amazon и H&M. Для A3 и A4 предсказания изменились в 15/15 seed-ячеек каждого слоя; средние по базам ΔAUC составили +0,0076…+0,0426 и +0,0944…+0,1653 соответственно.

**Вердикт:** механизмы проявились в данном контролируемом расширении. Это не все задачи баз и не полноценное повторение исходных моделей: для A3 использован random forest, для A4 — kNN; нарушения созданы протоколом.

**Источник:** [отчёт C2](../docs/experiments/c2-maintrack-remaining-databases.md).
