# C3 — свежая реимплементация механизмов Fonseca

Статус: завершено. Вердикт: **positive** — ожидаемые качественные границы
трёх механизмов воспроизведены. Пункт переведён из `in_review` в `done` после
завершения обязательных предшествующих ярусов N → H → A → B.

## Вопрос и правило решения

Воспроизводятся ли в независимой малой реализации три механизма из §8.3 при
прогоне через чекеры слоя признаков? Положительный результат требует ожидаемой
границы на всех пяти случаях каждого механизма и ноль срабатываний на пяти
корректных программах. Числа оригинальной статьи не реплицируются и напрямую
не сравниваются.

## Метод и результаты

Реализованы:

- M1 — неполное покрытие временных точек: фиксированная сетка пропустила 5/5,
  исчерпывающая проверка нашла 5/5;
- M2 — нечувствительность выбранного возмущения: физическое усечение нашло
  5/5, конкретный canary не изменил пороговый выход в 5/5;
- M3 — повторная маркировка будущего значения допустимым временем: проверка
  только заявленного timestamp приняла 5/5, физическое усечение и canary нашли
  5/5.

На пяти корректных программах truncation- и perturbation-чекеры дали 0/5
ложных срабатываний. Вердикт **positive / подтверждено** для качественной
реимплементации механизмов.

Пик RSS: 79.2 МБ; время: 0.07 с; один процесс и один поток.
