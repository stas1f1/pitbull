# H2 — контроли по слоям: первый безопасный прогон

## Вопрос

Распознаёт ли единое дифференциальное правило внесённое PIT-нарушение и не
срабатывает ли на корректной реализации для каждого из пяти видов базы?

## Предварительно зарегистрированное правило решения

Для каждого вида и каждого из пяти фиксированных моментов позитивный контроль
должен вернуть `LEAK`, негативный — `CLEAN`. Любое обратное наблюдение делает
результат `negative`. Этот прогон засчитывает только детерминированную часть
H2; требование измерить шум обучаемых модели/ICL по пяти seed остаётся
незакрытым.

## Метод

`prestudy/stack_controls.py` выполняет 5 видов: задача, признаки, модель,
ICL-контекст и агентский конвейер. В каждом — чистая реализация и одно
внесённое нарушение, на моментах `10, 20, 30, 40, 50`. Модель и ICL в этой
версии являются детерминированными стендами: обучение не выполняется.

## Воспроизведение и лимиты ресурсов

```powershell
$env:OMP_NUM_THREADS='1'
$env:OPENBLAS_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
D:\pitbull\.venv-a2\Scripts\python.exe D:\pitbull\pit_proposal_pkg\prestudy\stack_controls.py
```

Запуск не создаёт обучаемых моделей, использует один процесс и завершился за
8.3 с.

## Результат

| Вид базы | CLEAN | LEAK |
|---|---:|---:|
| задача | 5/5 | 5/5 |
| признаки | 5/5 | 5/5 |
| модель | 5/5 | 5/5 |
| ICL-контекст | 5/5 | 5/5 |
| агентный конвейер | 5/5 | 5/5 |

Итого: recall 25/25 = 100%; FPR 0/25 = 0% на этих контролях.

### Обучаемые модель и ICL

`h2_trained_controls.py` добавляет 20 однопоточных проверок: малая
логистическая модель на графовых агрегатах и 1-NN ICL-контекст. На пяти seed
для каждого вида получены 10/10 позитивных и 10/10 негативных результатов.
Максимальное изменение предсказания в позитиве: 0.058736 для модели и 1.0
для ICL; в негативе — 0.

### GNN-позитив

`h2_gnn_control.py` реализует вручную GraphSAGE-подобный слой на восьми
узлах. На пяти seed temporal sampler дал `CLEAN` 5/5, а sampler, допускающий
соседей после cutoff, — `LEAK` 5/5. Каждый из десяти запусков использовал
один CPU-поток и 20 эпох; обучение всего набора заняло 12.8 с.

## Вердикт

`positive / in_review`: все заявленные позитивные и негативные контроли
прошли на пяти seed; обучаемые модель, ICL и GNN-позитив измерены. Это
валидирует контролируемые реализации чекеров, а не подтверждает RQ3 на
естественных артефактах. Нужна человеческая проверка протокола перед `done`.
