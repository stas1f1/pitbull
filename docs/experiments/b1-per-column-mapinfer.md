# B1 — per-column map inference

Дата: 28 сентября 2026 года.

## Статус валидации

По прямому решению автора требование двух человеческих аннотаторов заменено
синтетической AI-assisted валидацией. Этот результат нельзя описывать как
human-validated. Референсом служит ранее сохранённый AI-проход по 179 полям;
второй проход выполнен независимыми короткими запросами к
`z-ai/glm-5.3-flash`, без передачи bootstrap-карты и сырых строк данных.

## Результат

| Метод | Class accuracy | Exact map agreement | Cohen's kappa |
|---|---:|---:|---:|
| Metadata heuristic | 97.2% | 94.4% | 0.769 |
| LLM map | 95.0% | 80.4% | 0.505 |

Пре-регистрированный исход «LLM-карта не хуже эвристики» не подтвердился по
основной метрике exact map agreement. Расхождения двух AI-проходов разрешены
консервативно: поле без согласованного проверяемого канала получает `unknown`
и исключается из операционной карты.

Внешний проход: 179/179 валидных ответов, 0 API-ошибок, 24,716 prompt tokens,
27,934 completion tokens, стоимость $0.0186.

Артефакты: `pilot/b1_results.json`,
`pilot/b1_provisional_operational_map.csv`, `pilot/b1_llm_item_responses/`.
